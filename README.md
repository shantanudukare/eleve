# Elevator Simulation (C++)

A simple **Elevator Simulation system built in C++** that demonstrates how elevators handle floor requests and move between floors.

## Features

- Multiple elevators
- Handles floor requests
- Shows elevator movement
- Console-based simulation
- Modular C++ structure

## Project Structure

## To Compile 
g++ main.cpp src/Elevator.cpp src/ElevatorController.cpp -Iinclude -o elevator

## To run file 

./elevator
